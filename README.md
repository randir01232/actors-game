# 🎭 Двойники

**Играть: https://randir01232.github.io/actors-game/**

Игра на память с подвохом: на карточках — фотографии двух звёзд, которых все путают
(Натали Портман и Кира Найтли, Элайджа Вуд и Тоби Магуайр, Эми Адамс и Айла Фишер…).

- В одной игре — **одна пара звёзд**, у каждой несколько разных фото.
- Нужно найти пары **одинаковых** фото. Сложно, потому что все фото выглядят одинаково.
- После каждой найденной пары можно угадать, кто на ней (+50 очков). Перепутать — нормально.
- В конце показывается «кто есть кто» и забавный факт про пару.
- «Пара дня» меняется каждый день. Рекорды хранятся в браузере.

Сложность: 12 / 16 / 24 карты.

## Запуск

Это статический сайт без сборки. Можно просто открыть `index.html` или запустить:

```bash
python3 -m http.server 8000
```

и открыть http://localhost:8000.

## Фото

Все фото взяты с [Wikimedia Commons](https://commons.wikimedia.org) по свободным лицензиям
(CC BY, CC BY-SA и т.п.). Они автоматически обрезаны по лицу (macOS Vision) и пережаты в WebP 360×360.
Авторы и лицензии каждого файла — в [credits.html](credits.html) и `img/credits.json`.

Пары двойников взяты из популярных подборок «celebrity lookalikes»
(Den of Geek, Business Insider, Marie Claire и др.).

## Структура

```
index.html        — разметка
css/style.css     — стили
js/game.js        — логика игры
js/data.js        — список звёзд, пар и фото (сгенерирован)
img/<звезда>/*.webp
credits.html      — авторы фото
```
